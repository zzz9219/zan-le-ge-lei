处理规则

只处理明确授权并固定的历史回填名单；范围扩展按视频 ID 去重，已完成内容不会重复处理。

先转写，再整理。历史批次先集中完成本地转写，再集中提炼，最后检查并停止。“待提炼”已有原始正文，可立即阅读，但要等转写阶段结束后再生成摘要。图文、无音轨、空识别和失败项记入异常清单，不无限重试。

每天 500 条是用量保护上限。这是日常新增的用量保护，不是系统只能处理 500 条。历史转写逐条串行，AI 提炼每批最多 5 条、正文最多 12,000 字，不等定时唤醒；额度不足时保留进度。已确认的最新点赞优先完成转写与提炼，再继续冻结的历史名单。

口播使用本地 Whisper 转写，不消耗 Agent 的模型额度。清理、摘要和分类才使用 AI；定时检查本身也会使用 Agent 的模型额度，只有你配置并启用后才会定时运行，可以选择中午 12 点和午夜 0 点。

图文、无可识别人声或失败的视频保留来源和原因，不编造文字。娱乐内容保留简短记录，知识内容重点提炼；原始转写始终保留。
