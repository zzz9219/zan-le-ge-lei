# 可选评论模块

基础点赞整理不需要本模块。需要只读采集某个视频评论时：

1. 安装 Node.js 22.5或以上；运行 `py -3.12 bootstrap.py --comments`。初始化在本机生成随机连接令牌，不向AI或GitHub上传。
2. 在你想用于采集的浏览器安装 Tampermonkey（内置浏览器须有扩展/用户脚本支持）。导入本地生成的 `comments/douyin-upstream/scripts/douyin.user.local.js`。这个文件含你自己的桥接令牌，留在本机。普通Chrome/Edge亦可；不要强制用户切浏览器。
3. 在该浏览器打开 `https://www.douyin.com/` 并自行登录；收藏采集用的独立登录浏览器与评论页是两个会话，首次评论可能需要再登录一次。
4. 回到学习库，打开笔记 → 评论深挖 → 采集高赞评论。服务自动启动本地19422桥，首次检查真实回执，后续复用已验证连接；无需播放完视频。若宿主在外部浏览器打开了视频，请回到装有脚本的浏览器保留一个抖音页，再点“检查浏览器连接”。

采集过程显示真实条数、页数和是否连接。默认最多1000条一级评论，每页展示10条，右侧导出全部已保存评论。按接口顺序采前部后按点赞排序，不声称全评论区最高赞1000条。失败/超时保存已采集结果，用户主动重试续采，不自动无限重试。

“等待已有任务”只应指另一评论任务；评论有自己的锁，不因Whisper转写而等待。运行过程中不要重启网页/桥。若浏览器不支持脚本，需要选择有该能力的本地浏览器；将来原生扩展或桌面集成尚未提供。

本模块不发布、回复评论，也不自动调用AI。关闭评论模块不影响点赞学习库。
